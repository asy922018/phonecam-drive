# 폰캠 드라이브

휴대폰 카메라 화면을 태블릿(또는 VR 기기에 넣은 휴대폰)에서 실시간으로 보는 웹 페이지입니다.
운전석에서 앞유리 너머를 보는 듯한 화면으로 카메라 영상을 보여 줍니다.

**주소:** https://asy922018.github.io/phonecam-drive/

## 사용법
1. 태블릿에서 주소를 열고 **운전석 (태블릿)** 을 누르면 앞유리에 4자리 코드와 QR이 뜹니다.
2. 휴대폰 카메라로 QR을 찍거나, 휴대폰에서 **카메라 (휴대폰)** 을 누르고 코드를 입력합니다.
3. 카메라 권한을 허용하면 앞유리에 휴대폰 카메라 화면이 나타납니다.

## 기능
- 계기판: 실제 전송 속도(Mbps)와 초당 프레임(fps)
- 센터 화면: 전체 화면, 꽉 채우기/전체 보기, 90° 회전, 좌우 반전, 소리, 캡처
- VR 모드: 카드보드형 VR 기기용 좌우 분할 화면
  - 렌즈 왜곡·색 번짐 보정, 고개를 돌리면 차 안을 둘러보기
  - 핸들·대시보드는 가깝게, 바깥 풍경은 멀리 보이는 입체감
  - 시작 전 설정: 왜곡 보정, 렌즈 간격, 입체감, 바깥 풍경 크기
  - 한 번 탭: 정면 맞추기 · 두 번 탭: 나가기
- 휴대폰: 앞뒤 카메라 전환, 화질 선택, 소리 보내기

## 레이스 모드 (마리오 카트 라이브 같은 놀이)
일반 RC카에 카메라 휴대폰을 싣고, 바닥에 깐 표지판을 인식해서 레이스를 즐깁니다.

1. [표지판 PDF](markers.pdf)를 A4에 **실제 크기**로 인쇄해 바닥에 깝니다. (게이트 1~4, 함정 A~D, 부스터 A~B, 화살표 2종)
2. 운전석 화면의 **레이스** 버튼에서 랩 수, 게이트 수, 게이트 사이 방향을 정합니다.
3. **표지판 테스트**로 인식을 확인하고 **레이스 시작**을 누르면 3, 2, 1, 출발!

- 게이트 1(출발선) → 2 → 3 → 4 → 1 순서로 지나면 1랩
- 함정을 밟으면 앞유리에 오물이 튀고 기록 +2초 (와이퍼로 닦기)
- 부스터를 밟으면 기록 −1초
- 화살표 표지판(오른쪽·왼쪽): 반 접어 텐트처럼 세워 두면 카메라가 알아보고 화면에서 화살표가 빛남 (꾸미기용, 레이스 밖에서도 동작)
- 화면에 다음 게이트 방향 화살표, 표지판 위 AR 표시, 효과음
- 결승 후 이름을 입력하면 기록판(상위 10개)에 저장 (기기에만 저장)
- VR 모드에서도 레이스 표시가 나오며, 레이스 중 탭하면 와이퍼

## 참고
- 표지판 인식은 [js-aruco2](https://github.com/damianofalcioni/js-aruco2)를 사용하며, 영상 분석은 태블릿 안에서만 이루어집니다.
- 영상은 기기끼리 WebRTC로 직접 주고받으며 서버에 저장되지 않습니다. 연결 코드 교환에만 PeerJS 공개 서버를 사용합니다.
- 같은 와이파이에서 가장 안정적입니다. 서로 다른 네트워크에서는 연결되지 않을 수 있습니다.
- 휴대폰 자동 회전을 켜고 가로로 들면 앞유리에 꼭 맞게 보입니다.
